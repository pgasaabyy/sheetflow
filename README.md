# sheetflow

Ferramenta de terminal para consolidar lançamentos financeiros: organiza, totaliza e resume dados de planilhas

> Projeto em desenvolvimento e todos os dados usados são fictícios

## Funcionalidades
- [ ] Listar lançamentos
- [ ] Adicionar lançamento
- [ ] Total geral e por categoria
- [ ] Maior e menor lançamento
- [ ] Importar CSV/Excel
- [ ] Gerar relatório em Excel

## Como usar
```bash
python main.py
```

## Tecnologias
- Python 3
